# Unify Tech - The Developers Handbook

An interactive flip-book documenting how the ARMS system (`ARMS.Frontend` + `ARMS.Backend`) was built.

Built with React + Vite. Page turning uses [`react-pageflip`](https://github.com/Nodlik/react-pageflip); the page-turn sound is synthesised with the Web Audio API (no audio file needed).

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run photos   # regenerate cropped author portraits from the originals
npm run snippets # re-copy the code shown on chapter pages from ../ARMS.Frontend and ../ARMS.Backend
```

Turn pages by clicking/dragging a page corner, with the arrow buttons, or with the ← → keys.

## Project structure

```
scripts/
  crop-author-photos.mjs     originals -> grayscale portraits + puzzle crops (crop boxes live here)
  extract-snippets.mjs       which ARMS files/lines each code excerpt shows -> src/data/snippets.json
src/
  assets/screens/            ARMS screenshots shown on chapter pages
  assets/authors/
    originals/               full-size photos as supplied (not bundled)
    cropped/                 600x800 portraits, generated by `npm run photos` (back cover)
    puzzle/                  600x600 wider crops, generated by `npm run photos` (front-cover puzzle)
  config/book.js             page aspect, flip speed, leaf indexes (page count comes from book/pages.js)
  book/
    pages.js                 ordered list of printed pages; paginates the contents; page numbers
    BookNav.js               context so any page can flip the book (e.g. contents links)
  data/
    authors.js               names, roles, photos, back-cover takeaways (display order)
    book.js                  title, "Written by" credit line, back-cover heading, dedication text
    contents.js              table of contents: 5 categories, groups and entries
    chapters/                chapter spreads per category (text, screenshot, snippet ids)
    snippets.json            generated by `npm run snippets` (don't edit by hand)
  hooks/
    useBookSize.js           fits the book to the viewport (two-page spread vs single page)
    useArrowKeys.js          ← → keyboard navigation
  lib/flipSound.js           synthesised page-turn sound
  components/
    book/                    Book (flip engine + open/closed shell), BookPage, BookControls
    covers/                  FrontCover, BackCover
      puzzle/                jigsaw geometry, puzzle layout (which cells are missing), PuzzleBackground
    pages/                   DedicationPage, ContentsPage (overview), TocPage (per category), TocEntry
    chapter/                 ChapterTextPage (left), ChapterCodePage (right), CodeBlock, ScreenImage, visuals/
    authors/                 AuthorPhoto (rounded portrait), AuthorCaption (name + role)
  styles/global.css          colour + font tokens, page background
```

## Common changes

- **Author details / takeaways** – edit `src/data/authors.js`.
- **New or replaced photo** – put the original in `src/assets/authors/originals/<id>.jpg`, add its crop box in `scripts/crop-author-photos.mjs`, run `npm run photos`.
- **Table of contents** – edit `src/data/contents.js`. Contents pages paginate themselves; long categories run onto extra pages.
- **Add a chapter** – each chapter is a two-page spread: the explanation on the left; on the right, an ARMS screenshot (click to hide it, "Show Image Again" to bring it back) above the code.
  1. Add the code ranges to `scripts/extract-snippets.mjs` and run `npm run snippets`.
  2. Put the screenshot in `src/assets/screens/`.
  3. Add the chapter to its category file in `src/data/chapters/`.
  4. Set `pageId` (the chapter id) on its entry in `src/data/contents.js`. The entry then shows its page number and becomes a link (until then it shows "soon").
- **Move a missing puzzle piece / resize pieces** – edit `slots` / `CELL` in `src/components/covers/puzzle/layout.js`.
